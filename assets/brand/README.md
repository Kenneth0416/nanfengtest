# Brand assets

The app logo is direction A ("Skyline", chosen 11 Oct 2026): a navy tower pair with an amber band on a
white tile, with the wordmark "London Office / MARKET AGENT". Master files and the two unused directions live
in the project's `branding/` folder; these are copies, and the file names here are final.

| File | Used where |
|---|---|
| `logo-horizontal.svg` (+ `@2x.png`, `-on-navy@2x.png`) | sidebar header, 212px wide (168px on a phone), caption "Prototype · sample data" |
| `nanfung/nanfung-logo-color.svg` | sidebar foot under a small "Built for" label, 118px wide, 1px rule beneath |
| `cobrand-nanfung.svg` (+ `@2x.png`) | Team brief page, header of the brief preview, up to 420px wide |
| `cobrand-nanfung-on-dark@2x.png` | deck covers, top right (rendered from `cobrand-nanfung-on-navy.svg` with the navy background removed, so it sits on every theme's dark cover) |
| `cobrand-nanfung-on-navy@2x.png` | the same lockup on a solid navy ground, for slides or pages that are navy already |
| `app-icon-1024.png`, `app-icon.svg` | the small mark beside the slide number on content slides; app icon |
| `favicon-32.png`, `favicon.svg`, `favicon.ico`, `apple-touch-icon.png` | browser tab (`st.set_page_config(page_icon=favicon-32.png)`); the SVG, ICO and touch icon are for any plain HTML page |

Rules: the Nan Fung mark appears only through the co-brand lockup or the "Built for" foot, never beside the app
logo by hand; keep the lockups' own clear space; the horizontal logo goes no narrower than 160px and the Nan Fung
mark no narrower than 72px; colour versions on light grounds, the on-dark versions on navy or dark grounds; no
logo on photographs or amber.
